# Security Policy

Phoneal is an early experimental prototype and is not production-ready. Do not use it to execute untrusted programs.

The current interpreter has no sandbox, capability-based filesystem/network permissions, verified bytecode, signed package system, or independent security audit. Static type checking and lexical scopes are correctness features, not security boundaries. The security-first goal is not a claim that the current implementation is secure or unhackable.

Please report suspected vulnerabilities privately through GitHub's security reporting feature if enabled. Avoid publishing exploitable details in public issues.
